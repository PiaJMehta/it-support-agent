---
id: printer-offline
title: Printer shows offline
team: IT Helpdesk
---
If a shared printer shows offline, check that it is powered on and shows no paper jam or error on its screen.
Remove and re-add the printer from the print server list.
Print a test page. If other users on the same floor also see it offline, the IT Helpdesk will check the print server and the printer network cable.
