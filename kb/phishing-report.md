---
id: phishing-report
title: Suspicious email, phishing link or entered credentials
team: Security
---
If a user clicked a suspicious link or entered credentials on an unknown page, treat it as a security incident right away.
Tell the user to disconnect from the network if malware is possible and not to log in anywhere else.
The Security team resets the password, revokes active sessions and checks the account for suspicious sign-ins.
Report the original email with the Report Phishing button. Never ignore these tickets.
